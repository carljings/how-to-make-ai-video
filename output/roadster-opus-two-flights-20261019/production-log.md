# Production log —《看不见的十吨》（Opus 5.5 主创/实现；Codex 制作助理）

所有判断基于我亲自查看的实际渲染帧（SwiftShader，本服务器）。没有人连续观看、试听或在实体手机上验收。

## 2026-10-19
1. **环境核查**：Node 24、npm 可联网、ffmpeg 6.1、Chrome（SwiftShader）、4 核、根分区仅约 2 GB 空闲。→ 决定不用 Remotion（依赖与浏览器下载约数百 MB），自写 three.js + Canvas 2D + CDP 渲染器，**逐帧 PNG 经管道直送 ffmpeg，不落盘帧序列**。依赖只有 three 0.186.1（23 MB）。已核对本地包导出（NeutralToneMapping、PMREMGenerator、UnrealBloomPass 等）。
2. **诊断 V9**（看其编码抽帧）：无可感知的“哇”量、画面暗散、概念过多、字小。→ brief.md 比较三条路线，选 C“看不见的十吨”（棚拍 3D + 大胆 2D 量化 + 一镜到底证明）。
3. **资产**：复用 V9 第三轮车/坡网格与位姿（含翻滚方向 −1 修正）；Noto Sans SC 用 Google Fonts `text=` 子集化（OFL）。
4. **第一轮关键帧（stills1）**：3D 严重过曝——泛光灯按物理坎德拉设得过高、环境光过强、泛光阈值过低。→ 灯强降约 6 倍、环境 0.22、阈值提高。
5. **stills2–6**：坡边红霓虹被色调映射洗成橙（后处理链中材质 toneMapped 无效）→ 改 NeutralToneMapping；空气粒子近处成“雪片”→ 限制像素尺寸；答案镜头受力箭头被车体遮挡 → 箭头关闭深度测试、穿车绘制；开场过近、车灯眩光 → 改倒挂车头 3/4 再调。
6. **stills7**：EffectComposer 无多重采样导致桁架锯齿 → 4× MSAA 半浮点渲染目标；加入落地泛光灯的假体积光柱。
7. **stills8–10（2D）**：网格投影的车轮廓参差难看 → 改为按同一车模比例绘制的干净侧影图标；“密封/抽气/风扇”标签互压 → 重新横向排布（前轮｜风扇｜合力｜重力｜后轮）、引线标注；空气柱上升时增加“蓝天→太空”渐变。
8. **第一版整片联络表（contact1，每秒一帧）**自审：开场 8 s 构图单一、拉远不够有力；空气柱中段空屏；气云糊白；答案镜头偏静。
9. **助理科学核对**（4.9 kPa/5% 是准静态只平衡重力的下限）→ 采纳：屏幕改为「举例：2 吨车，车底 4 ㎡ / 至少低约 5% / 只够托住重量，开起来要更多」，并从 S6 起整体顺延 2.2 s 保证阅读时间（END 52.0 → 54.2 s，1626 帧）。
10. **v1.1 改动**：开场改为从倒挂车头近景加速拉远、下摇到地面（高度揭示）；S2 换侧下方新角度、粒子加强；空气柱高空分子与刻度加强；气云改灰、降不透明度；答案镜头加大环绕与推近。
11. **配乐**：`tools/score.mjs` 加法合成，100 BPM 轻脉冲；翻身时每个可见面一个音、“接住”时 Gmaj7 展开、答案回到 D 大调；结尾 0.4 s 静音。自测 −20.00 LUFS / −7.08 dBTP（与 ffmpeg ebur128 一致）。
12. **第一次整片渲染中途叫停**：写了 `tools/textcheck.mjs`（每行落定后停留 ≥ max(1.2, 0.4+0.2×字数) s；整卡同理；同区域不交叠）。v1.1 有 10 张卡不达标、4 处交叠——手机上读不完。这比片长更重要。
13. **v1.2 时间轴**：S4 15.4–22.4、S5 22.4–37.0、S6 37.0–40.0、S7 40.0–51.6、S8 51.6–61.0；END 61.0 s（1830 帧）。“离开坡面，压差就没了”并入“坡有尽头”卡，整卡在车离开坡面时逐字掉落。textcheck 全部通过、无交叠。配乐随 T 自动重排：−20.00 LUFS / −7.67 dBTP。
14. **整片渲染**：`node tools/render.mjs --video --workers 2 --split 1201`（按 3D/2D 耗时估算切分；见下方“最终核验”）。

## 2026-10-19 · v1.2 审看反馈 → v2
用户看了 M4 渲染的 61 s v1.2 后原话：“车子太亮了，然后节奏再快点，音乐再动感些”。我看了助理抽的实际编码帧，判断：
- **太亮**：白车漆（0xdcdee1）在落地主光 + 环境光 + 泛光下大面积逼近纯白，车灯成光团，体积和层次丢失。
- **慢**：61 s 里每张卡停留偏长、开场与车底剖面同一构图过久、运镜偏缓；配乐 100 BPM 的轻脉冲没有律动骨架。

v2 实施（全部由我改源码）：
1. **车**：车漆改珍珠银白 0xa9aeb5（粗糙 0.42、清漆 1.0、envMapIntensity 1.35）——体积来自反射与轮廓光；车灯 1.15；泛光阈值 1.55（车漆不再发光）；逐镜头压低正对车身的落地主光（S2 0.45–0.65、答案 0.55）、着陆灯 ×0.6、底部补光降低。实测关键帧 >250 灰阶像素 ≤0.1 %。
2. **节奏**：120 BPM 剪辑网格，所有切点/揭示在拍上；全片 61 → 42.3 s（1269 帧）。字卡入场 0.3 s、逐字 0.022 s；切点处 3D 视角冲击、2D 缩放冲击；2D 场景随强拍轻呼吸。车底剖面拆成三段运镜（全景 → 推近 → 拉远看大号压力条）。答案镜头按力箭头随强拍脉动。删去“而且不只往下压”（放射箭头已表达）。
3. **阅读规则 v2**：每行 ≥ max(0.8, 0.3 + 0.13×字数) s，整卡 ≥ 0.3 + 0.11×总字数（约 8 字/秒）；用户明确它不是硬指标，这是我为“更快”设的底线。textcheck 全过、无交叠。
4. **配乐 v2**（`tools/score.mjs`）：柔和正弦踢鼓（110→45 Hz、5 ms 起音、轻 tanh 饱和）、八分音符贝斯、十六分琶音、反拍短奏、Pad 旁链式呼吸；掉落时律动全部抽空，只留翻身上行钟声，31.0 s“接住”在强拍上回落。分轨实测：琶音≈Pad≈低频≈−25 LUFS（各段）。真峰起初 −4.9 dBTP，逐一定位峰值时刻（31.5、9.05、37.3 s）从源头处理（踢鼓瞬态、低频叠加、Pad 声部），不加限幅器：最终 −20.00 LUFS / −6.85 dBTP。
5. **工具修复**：verify.mjs 黑场改用 `metadata=print:file=-` 读 stdout（v1.2 旧成片复测得 9 帧 Y=16）；render.mjs 联络表在无 drawtext 时退回无标签版，失败则非零退出。
6. **未在服务器跑整片**（按用户与助理安排）：冻结源码后由 Codex 在 M4 渲染整片并回传编码证据，我再审看。

# v3《两次起飞》— 2026-10-19（Opus 5.5 后续制作；Codex 执行）
用户原话：“两段飞行视频都要讲到，节奏再快点，效果原理再酷炫些，bgm注意不要声音变小了，镜头踩到bgm鼓点上”。本节覆盖上面 v2 的“删 kickflip 支线 / −20 LUFS / −8 dB duck / 120 BPM 网格”等决定。所有判断基于我本人看过的服务器实际渲染帧（SwiftShader）与实测音频数据；**没有人连续观看或试听过 v3**。

1. **接手检查**：上一制作阶段留下的 `world3d.js` 已加载停车场/kickflip 资产但 `film.js`/`timeline.js` 仍是 v2，且 `film.js` 调用的 `world.local/com` 已被删 —— 整体不可运行。决定重写时间线、合成与音频流程，复用并扩展 3D 引擎。
2. **看原片**（两段都已上传，未放入成片）：坡道原片 15.4 s/60 fps：车爬弯道 → 倒挂 → ~9.7 s 离坡 → 半滚回正 → 喷气 → 落入气云。停车场原片 45.6 s/24 fps：~5.5 s 车从气云中出现、四股向下喷流升起、约 6.5–10.3 s 一整圈左滚、放平下降；画面左侧可见细线。
3. **音乐实测**（`tools/music_analyze.py`，重写）：141.94 BPM；八分音符处处有起音，按“歌曲第一击 = 小节线”取 0.061 s，并用 1–4 kHz 拍手声折叠验证（第 3 拍最强，半速反拍）；原曲自身停顿 3.46–4.82 s（以 −30 dBFS 测，3.44 s 正是小节线）；低音抽空 30.50–31.76 s；硬切 36.01 s；平台片尾声 37.07–37.48 s。修正了前一版本的两处问题：小节相位用低频通量 argmax 取到了 1.5 拍偏移；停顿用 −40 dBFS 只测出 3.70–4.53 s。
4. **结构决定**：片时间 = 曲时间，原曲 0–35.96 s 一刀不剪。四小节乐句线（5.13 / 11.90 / 18.68 / 25.42 / 32.21 s）做段落边界；**原曲停顿 = 车冲出坡尽头**（静音里 0.63× 慢放半滚，鼓点回来时喷气接住）；低音抽空小节放“细线作用未知”。冷开场先把两段动作看全，再“倒带”进原理。
5. **方向比较**（brief.md）：A 原片 + 叠加（竖屏裁切后车太小，且复用第三方画面）/ B 全 2D（课件感）/ **C 冷开场 + 3D 原理空间** ✔。
6. **新 3D 手段**：激光把倒挂的车剖开（两枚裁切平面取交集 + 车身截面掩模：由车模在 y=0 的截面线段光栅化后从边界泛洪填充；缝隙 = 车底到路面、地板跨度内；模糊场画等压线）；切面着色器画外部高压分子/车底低压蓝带/尾部抽气流/两端密封；力矩实验室（网格地面、两台同车、推力作用线、重心、力臂、力矩弧）；第二台车与第二套喷流；3D→屏幕投影标签；储气表；倒带运动模糊（多子帧平均）。
7. **第一轮 26 帧**：A1 机位在弯墙外侧看不到车；剖面推得太近、车形认不出、点太密；停车场地面发灰；B4/结尾不跟车；实验室 B 车被轮廓光打成白团。
8. **第二～四轮**：A1 机位移到弯道内侧；剖面先全车再推到车尾；实验室轮廓光 900→380 cd、去掉地下补光、车灯 ×0.35；地面灰是 RoomEnvironment 在掠射角的菲涅尔反射 → 停车场地面 envMapIntensity 0.12、环境 0.14；A2 车被主光+车灯打得发白 → 主光 0.4、曝光 0.84、车灯 1.15→0.95；结尾总结字移到下方。
9. **全片每 6 帧联络表（182 帧）**审看：冷开场节奏与翻身可读；剖面从下往上看时车形被压成一条，改为与车同高的侧视（远侧车轮在缝隙里露出，认得出是倒挂的车）；停车场喷流在加法混合下比车亮得多，把车吞成白团 → 喷流 ×0.55、粒子更小、B3 机位拉远到 10.5 m；P4 气云发白 → 透明度 ×0.45；坡边灯条太亮 → 0.22；车底板反射环境灯盒成白板 → 粗糙 0.72、金属 0.25、envMap 0.5。
10. **字卡**：16 张、157 个汉字；v2 阅读规则（约 8 字/秒）。卡与卡在切点处交叠 0.1–0.2 s → 新增 exit 'cut'（随画面切点在同一帧消失），并按帧取整（修了 f509 上一张卡残留一帧的问题）；实验室文字改为对仗短句「穿过重心/只推不转」「偏开重心/就会翻转」。textcheck 全过、无交叠。
11. **踩点**：28 个 cue 全部吸附到检测起音；S3 原本要求 20.0 拍处只有一个弱低频起音（独立检测器在 MP4 上找不到）→ 改到 19.3+½ 的强全频起音。剪切帧与最近检测起音最大差 17 ms、平均 7.6 ms；另加强起音（强度 ≥ 3.5）上的轻微镜头呼吸。
12. **音频**（`tools/bgm.mjs`）：增益 0 dB，无 duck/压缩/限幅/剪接；master 未淡出段 −10.4 LUFS / −2.1 dBTP，与原曲同段一致（按助理提醒，峰值以原生立体声测；单声道下混的 >1.0 只是相干下混 +3 dB）。片尾按助理提醒统一：音频 35.96 s 起、画面 35.93 s 起全黑全静，END 36.3 s，verify 的“末 0.3 s 静音 + 黑场”与设计一致。
13. **核验工具**：`verify.mjs` 新增“与原曲同段响度差 ≤ 0.5 LU”、真峰 ≤ −1 dBTP、与原曲互相关时延 ≤ 1 ms；`sync_check.py` 从 MP4 本身检测画面硬切（帧差）与音频起音（四频带归一化谱通量）。用服务器替身视频（每镜一种灰度 + 真实 master）跑通：9 项全过，时延 0 ms、相关 1.0；20 个计划切点全部在 ±0 帧被检出；最大 |帧−起音| 17 ms；停顿切点比实测静音晚 7 ms。
14. **服务器视频管线**：f500–f530 实际编码 31 帧，确认 f509 切点上一张卡已消失。整片未在服务器渲染（按安排由 M4 跑）。
15. **冻结**：`out/v3-source.sha256`（28 文件）；执行单 `ASSISTANT_ORDERS.md`。

## v3.1 — 只修核验工具（2026-10-19，台北 22 点后）
