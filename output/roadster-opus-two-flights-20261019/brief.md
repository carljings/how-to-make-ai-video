## 和上一版（v2，42.3 s）相比必须改变的
1. **第二段演示回来**：停车场起飞翻转（kickflip）独立成段，有标题卡“演示②”，换场景/换时间，不和坡道接成一次动作；原片可见细线保留并说明“作用未知”。
2. **更快**：36 s 讲两段演示 + 三个原理（v2 42 s 只讲一个）。镜头平均 ≈ 1.7 s（一小节），最短 0.85 s；没有 v2 那种 10 s 的静态剖面课件。
3. **原理更酷**：原理都在 3D 空间里、跟着动作发生——
   - 压差：一道激光切面把倒挂的车**剖开**，切面上实时显示气压场（外面橙色高压、分子密集撞击；车底蓝色低压、稀疏；风扇把车底空气从后部抽走；侧边密封发光）。车驶出坡尽头时，蓝色缝隙被外面空气**灌满**，橙色按力箭头当场缩没，车掉下去。
   - 反推：喷流粒子向下，薄荷色反作用箭头向上，白色速度箭头仍朝下但变短（“推力向上≠一定上升”）；储气表随喷气下降。
   - 力矩：黑色“力矩实验室”里两台同样的车并排对照——作用线穿过重心只推不转；作用线偏开一个力臂就绕重心翻转；再回到停车场原动作上叠加重心与翻转弧。
4. **踩点**：所有剪切与主要揭示都吸附在 `tools/music_analyze.py` 检测出的鼓点上（`src/music.js` 由分析脚本生成，时间线按“第几小节第几拍”取检测到的起音，找不到就报错，不能用网格冒充）。原曲在 3.46 s 自己停一小节——车恰好在这一刻冲出坡尽头，静音里慢放整个翻身，5.13 s 鼓点回来时喷气“接住”。
5. **音量**：去掉 −8 dB duck 与 −20 LUFS 目标；整片与原曲同响度。

## 表达方向比较 → 选择
| 方向 | 做法 | 取舍 |
|---|---|---|
| A 两段原片 + 图形叠加 | 直接用两段原视频，上面画箭头 | 原片横屏、车很小，竖屏裁切后几乎看不到车；第三方画面直接复用；原理只能“贴”在平面上 |
| B 全 2D 动态图解 | 扁平动画讲三个原理 | 快、清楚，但回到“课件感”，用户要的是更酷 |
| **C 冷开场 + 3D 原理空间 ✔** | 先用 CG 重建把坡道最炸的一下（倒挂→冲出→翻身→喷气接住）踩着原曲的停顿放完，再“倒带”回去把车剖开讲压差；第二段同样先看完整翻转，再进力矩实验室 | 钩子最强；原理和动作在同一空间里；两段演示各自完整；都是已拟合资产，可控、可标注 |

## 必须
- 两段演示都完整出现，翻转动作看全（坡道翻身 0.63× 慢放，停车场整圈约 1:1）。
- 科学底线（V9 SCIENCE_AUDIT A01–A22 + OpenStax 10.6 力矩）：压差靠风扇 + 密封维持低压，离开坡面后不能再靠它；喷气是反作用推力，不靠撞地；推力向上不保证上升；转动看合转矩（作用线与力臂），不拿一个喷口或几束可见喷气证明真实控制；储气有限要补；停车场细线保留并标“作用未知”；CG 重建、示意、慢放/变速全部标注。
- 保留珍珠银白车漆与高光层次（v2 材质），任何光效不得把车照成白团（关键帧 Y′>250 像素占比检查）。

## 避免
冒充实车内部布局（风扇、气罐、喷口位置都只在示意里）；“不是吸是压”伪二分；“推力向上所以上升”；把两段接成一次飞行；把细线抹掉；静态长镜头。

## 成功标准（可在实际帧上检）
- 第 0 帧就有主体；前 2 s 立住问题。
- 每个剪切点距最近检测鼓点 ≤ 1 帧（33 ms）；cue 清单可核对。
- 两段演示 + 三个原理各有专门镜头；每张字卡停留满足 v2 阅读规则（约 8 字/秒）且不交叠。
- 编码后整合响度在 −10.4 ± 1 LUFS，真峰 ≤ −1.0 dBTP，结尾自然淡出后静音。

是否真的“更酷”、听着是否舒服，需要用户本人看/听；我只能报告实际帧与测量。

# v4 增补（2026-10-19，用户看完 v3.1 后）
用户原话：“左右喷气的位置没有，然后特效镜头 节奏再惊艳 震撼些”。

**先看证据**（两段原片放大裁切逐帧，`production-log.md` v4 第 1 条）：停车场原片翻滚时，车身**两侧边缘、前后两端**都能看到喷流（7.9 s 上下两缘同时有，8.2–8.5 s 倒置时从朝上的车底喷出，9.1–9.4 s 两缘都有，10.0 s 车头向前一股）；坡道原片半滚时车侧/车底已有喷流（9.93、10.43 s），10.6 s 起车头向前一股，10.93 s 起四股向下。结论：**“左右两侧、前后都有喷口”有可见证据**；具体位置、角度、何时喷多大**测不出来**——片中一律标“示意位置 · 据两段原片可见喷流 · 非原厂图纸”。

**v4 的回答**
1. **喷口地图**（bar 10，16.97–18.68 s，原 B1 停车场空镜的位置）：实验室里一台车，镜头从**车后**绕（车的左 = 画面左），每个喷口发光标记、按侧着色（左青、右粉、车头白）；鼓点 10.1 左侧组喷、10.2 右侧组喷、10.3 车头 + 底部四角一起喷，每次带冲击环和镜头冲击。字「左右都有喷口」。
2. **力矩实验室改为左右对照**：A 左右一起喷 → 推力过重心 → 只升不转；B 只喷左边 → 力臂 → 力矩 → 翻滚一整圈；下一小节 B 右边反喷 → 反向力矩 → 转动停住、回到水平。也就是“用左右喷气做一次 kickflip”。从车后拍，左右不颠倒。
3. **停车场真实翻转回放**改为从车后看，左右喷口按侧着色并标「左侧/右侧」，字「左右推力差 → 力矩」；角标写“各喷口何时喷、推力多大：未公开”。
4. **更惊艳的节奏/特效**：原曲停顿里离坡后**子弹时间**（车侧立时几乎定格、镜头绕车约 50°）；停车场翻滚中段**子弹时间**（喷流冻结在空中、镜头绕车约 120°，在强拍 12.3 上 2.4× 甩回）；点火冲击环（接住、升空、喷口地图、实验室每次点火）；大鼓点上的径向变焦拖影；强起音上的确定性镜头震动、更强的镜头呼吸。
5. 不变：同一首原曲 0 dB、片时间 = 曲时间、所有切点吸附检测鼓点、两段演示与三个原理、细线“作用未知”、无旁白、车身不过曝、36.3 s。
