# 魔方 r6：加了冲击动效的 full 版

[English](README.md) · **简体中文**

r6 是 r5 的 `full` 版（126.5 秒，时间线、字幕和配乐不变），加了一层让观众眼前一亮的动效。用户对 r5 的意见：“动效不够酷、不够惊艳，要让观众眼睛一亮”。成片：`out/rubiks-r6-full.mp4`（−14 LUFS），另有画面相同的 `out/rubiks-r6-full-loud.mp4`（−10 LUFS）供抖音使用，用户此前几部抖音片都选了更响的版本。

新增 `src/lib/fx.js` 和 `src/hero.js`，全部是帧时间的纯函数（固定种子随机，无状态）：

- **每一帧**：四分之一分辨率的泛光（模糊并提高对比度的副本以滤色叠回画面），加上有视差的漂浮微尘。
- **每个重音**：镜头震动和推近、扩散冲击波环、魔方贴纸碎片、亮火花，主角数字带 RGB 分离。
- **主角时刻**：
  - 开场还原时镜头急推，带速度线
  - 2.51 砸下时背后红色光芒，20 落定时紫色光芒
  - 爆炸时金色冲击波，4325 亿亿背后金色光芒
  - 搜索圈每长一步有脉冲，外圈有光点绕行
  - 两边搜索相遇时迸发
  - 证明网格随扫描逐块翻牌
  - 20 砸下时全片最大的爆发
  - 2.51 落定时冲击波，印章下扬起红色粉尘
  - 解法每完成一个阶段有光环，每次还原后有高光扫过
  - 3.51、4.20、4.81 揭晓时有火花
  - 结尾聚光光束

魔方渲染、字幕、版式和事实沿用 r5。配乐只在开场急推下加了一声呼啸。

渲染：`tools/render-r6.sh`（三个 Chrome 进程分段渲染，再拼接、生成配乐、母带、校验）。三路并行约需 5.4 GB 空闲内存，先用 `free -m` 检查。做了哪些检查、渲染中的内存耗尽事故和局限见 [PRODUCTION_LOG.md](PRODUCTION_LOG.md)。配乐没有人试听过。
