## Archive integrity

Media asset bytes are unchanged and independently hashed. Publication-only edits remove private operating data, replace account/session logs with technical summaries, and update download links. Historical production source hashes describe the original production snapshots; the Git commit identifies this public archive. Existing code formatting and upstream licence text are preserved. The bundled [font licences](licenses/) supplement each project’s own credits.
