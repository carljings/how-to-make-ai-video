2026年10月9日。V1、V2保留在相邻目录。本目录早先的Canvas草稿（上一会话中断，未渲染成片）移到 `canvas-draft/`，未提交，已被本版取代。

## 用户的决定

| 时间 | 决定 |
|---|---|
| 上一会话 | 不要旁白，像参考片一样由画面字和配乐讲故事；母带约 −10 LUFS（仓库规则是 −14 LUFS，本片例外）；分镜可以开工 |

## 按判断做的改动（相对上一版分镜草案）

| 改动 | 理由 |
|---|---|
| 开头从“诺奖+神经元放电”改成“小鼠灯亮就跑、灯灭就慢” | 第一秒给一个不需要背景知识的反常识现象；诺奖仍在首帧（金色小标），片名推到第6秒 |
| 0–6秒抛出“它的脑子里藏着什么开关”，51秒“回到开头”揭晓 | 开放式悬念撑住中段；原分镜的小鼠实验从第9幕挪到片头和第6幕两处 |
| 新增18–22秒“猜一猜”三选一 | 片中互动点，也是“发现”这一幕的入口；干扰项萤火虫、水母都和光有关但不对 |
| 片尾新增讨论卡 | 与内容相关的开放问题和三个选项；不要求点赞或关注 |
| 新增章节进度条（现象/难题/发现/原理/改造/控制/验证/应用） | 让观众知道走到哪一步；字号小，不抢标题 |
| 64秒、120 BPM，切点落在拍点 | 画面节奏和配乐同一网格；光脉冲本身就是打击乐 |

## 实现

| 部分 | 做法 |
|---|---|
| 框架 | Remotion 4.0.534 + React 19；每幕一个 `<Sequence>`，在 Remotion Studio 时间线上按名字显示 |
| 时间 | `src/timeline.ts` 是唯一时间来源：场景、文字、光脉冲、转场、配乐事件都从这里读 |
| 画面 | 发光线描和粒子画在每幕自己的 canvas 上（光点精灵、发光线、四分之一尺寸泛光，移植自 V2/V3 的绘制工具）；文字、HUD、卡片、示波器、音序器、讨论卡是 React/SVG |
| 动效 | 逐字弹出、关键词变色加下划线、翻牌字、滚动计数、锁定框、穿越变焦（放射速度线）、故障切、圆形展开、甩镜头、重击切、橙色漏光、命中闪光与镜头震动 |
| 声音 | `src/audio/score.ts`：Web Audio 离线合成，D小调120 BPM；侧链压缩、分段滤波、灯灭收窄、掉落前一小节抽掉鼓、48秒磁带停转、脚步落在小鼠模拟的后脚着地时刻；在无头 Chrome 里渲染，ffmpeg 母带 |
| 字体 | Noto Sans SC、Noto Serif SC、JetBrains Mono 子集，随项目保存 |

## 审片中发现并改掉的问题

| 问题 | 处理 |
|---|---|
| 首帧被开场闪光整体提亮成灰蓝色，小标和关键词颜色还没出现 | 首帧不加闪光；第一块字从第0帧起就完整（金色小标、蓝色关键词、章节条）；小鼠从小跑开始，静帧也有动感 |
| 31个字（多为标签和卡片上的字）不在字体子集里，渲染时退回系统字体 | 写完所有文字后重新生成子集；verify 增加字体覆盖检查 |
| 鼓、贝斯起音和光脉冲的低频叠在同一拍上，峰均比约16 dB，限幅器要压约9 dB | 鼓组单独软饱和；推动型贝斯挪到反拍；拍上的光脉冲不再叠低频；限幅后约4–5 dB，只压瞬态 |
| AAC编码后真峰值 −1.4 dBTP | 限幅器阈值从 −2.0 改为 −2.4 dB，成片 −1.5 dBTP |
| 21.5秒揭晓后圆形展开开始太早，答案只露出不到半秒 | 衣藻一幕推迟到22.4秒开始 |
| 22.4秒衣藻一幕从小节中间开始，铺底和弦要等下一小节才进，出现空洞 | 场景从小节中间开始时铺底立刻进入 |
| 鞭毛、通道标签压在细胞上；“中脑运动区”标签压在仪表上；闪光偏重 | 改位置；闪光强度下调 |
