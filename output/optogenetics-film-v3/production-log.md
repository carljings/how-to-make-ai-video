## 按判断做的改动（相对上一版分镜草案）

| 改动 | 理由 |
|---|---|
| 开头从“诺奖+神经元放电”改成“小鼠灯亮就跑、灯灭就慢” | 第一秒给一个不需要背景知识的反常识现象；诺奖仍在首帧（金色小标），片名推到第6秒 |
| 0–6秒抛出“它的脑子里藏着什么开关”，51秒“回到开头”揭晓 | 开放式悬念撑住中段；原分镜的小鼠实验从第9幕挪到片头和第6幕两处 |
| 新增18–22秒“猜一猜”三选一 | 片中互动点，也是“发现”这一幕的入口；干扰项萤火虫、水母都和光有关但不对 |
| 片尾新增讨论卡 | 与内容相关的开放问题和三个选项；不要求点赞或关注 |
| 新增章节进度条（现象/难题/发现/原理/改造/控制/验证/应用） | 让观众知道走到哪一步；字号小，不抢标题 |
| 64秒、120 BPM，切点落在拍点 | 画面节奏和配乐同一网格；光脉冲本身就是打击乐 |

## 实现

| 部分 | 做法 |
|---|---|
| 框架 | Remotion 4.0.534 + React 19；每幕一个 `<Sequence>`，在 Remotion Studio 时间线上按名字显示 |
| 时间 | `src/timeline.ts` 是唯一时间来源：场景、文字、光脉冲、转场、配乐事件都从这里读 |
| 画面 | 发光线描和粒子画在每幕自己的 canvas 上（光点精灵、发光线、四分之一尺寸泛光，移植自 V2/V3 的绘制工具）；文字、HUD、卡片、示波器、音序器、讨论卡是 React/SVG |
| 动效 | 逐字弹出、关键词变色加下划线、翻牌字、滚动计数、锁定框、穿越变焦（放射速度线）、故障切、圆形展开、甩镜头、重击切、橙色漏光、命中闪光与镜头震动 |
| 声音 | `src/audio/score.ts`：Web Audio 离线合成，D小调120 BPM；侧链压缩、分段滤波、灯灭收窄、掉落前一小节抽掉鼓、48秒磁带停转、脚步落在小鼠模拟的后脚着地时刻；在无头 Chrome 里渲染，ffmpeg 母带 |
| 字体 | Noto Sans SC、Noto Serif SC、JetBrains Mono 子集，随项目保存 |

## 第三轮：用户看过PR #3之后（10月9日晚）

用户反馈：最后13秒（51秒起）背景音乐“滋滋”刺耳；要抖音发布各栏的填写说明；要更吸引人的封面；结尾要更能引发讨论、更有意义。

**配乐“滋滋”的排查**（没法听，只能测）：

| 测的 | 结果 |
|---|---|
| 51秒以后与片头的频谱对比 | 片头的高频在鼓点之间是暗的；51–56秒被连续的宽带噪声填满，57–58秒有调频钟声的金属泛音，59–60秒是白噪声上升音，60–62秒是长镲 |
| 分轨渲染（音乐、鼓、音效、混响分别输出） | 51–56秒6 kHz以上的能量主要来自鼓组：16分音符沙锤（起音8毫秒，连成一片）加16分踩镲；母带限幅器每拍压一下，这片噪声就跟着“滋、滋、滋”地起伏 |
| 母带软削波器的输入范围 | WaveShaper只覆盖±1，超出就硬削波：0、6、38、51、60秒的重音各有约6毫秒被削平，会有一下“咔” |

**改动**：去掉沙锤；51秒起踩镲减半、琶音改八分音符；51秒以后的铺底从锯齿波改成三角波；临床和片尾不再有踩镲；59–60秒的白噪声上升音换成无噪声的上行音；镲片缩短并滤掉最高频；钟声的调频深度减半；母带先减半再过tanh(2x)，±2以内都不硬削波。改后频谱里51秒以后的连续宽带噪声消失；响度仍是 −10.1 LUFS，响度范围从2.8 LU变成4.2 LU（结尾真的安静下来了）。

**新结尾（片长64→70秒）**：

| 时间 | 内容 | 为什么 |
|---|---|---|
| 60–64秒 | “起点，只是一个好奇：绿藻为什么追光？”一道光沿时间轴点亮 2002 绿藻追光 → 2005 装进神经元 → 2021 帮助视网膜 → 2026 诺贝尔奖；副行“没人想到：近二十年后，它帮一位盲人重新感知到物体” | 给观众一个转发的理由：基础研究里的好奇心，走到了临床和诺奖 |
| 64–70秒 | 片名，然后辩论卡：“如果有一天，光能调节情绪，你愿意用在自己身上吗？”A 愿意 / B 不愿意，高亮随拍来回；小字“目前只在动物实验中做到” | 原来的“你想研究什么”是选菜单；辩论题每个人都有立场、都能讲理由，更容易形成讨论；小字防止误解 |
