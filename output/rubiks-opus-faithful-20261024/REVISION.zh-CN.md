# 按 Opus 原版方式修订 r3

用户明确要求沿用 Opus 的审美和制作方式。本稿从原版 r1 建立独立副本，上一稿 r2 另外保留。

本次只修三处：

1. 锁定标记跟随换位后的真实角／棱。仍用原版的小红锁和文字，在目标块上方紧凑排列，避开主标题。
2. F2L 配对编号修正为 1–4。保持原机位、强调方式、动作时间与材质。
3. 阶段标签提前为勾号预留宽度；字体、字号、颜色和胶囊样式沿用原版，完成时不推挤其他标签。

渲染输入中只有 `src/scenes/count.js`、`src/scenes/methods.js` 改动。158 秒时间轴、真实动作序列、配乐源码、字体、核心绘制和 Chrome 导出程序均与原版相同。

按用户明确指定的原方式，使用原独立 headless Chrome 渲染命令，只渲染本地影片，使用新的临时 profile，不接触账号或日常浏览器数据。

原版由 Web Audio 生成的 AAC 音轨直接复用，不重新合成、不重新编码。43 个原画面分块（3840 帧）直接复用，10 个涉及修正的分块（900 帧）用原渲染器重做，再由 FFmpeg 封装。

检查画面／音轨编码数据、时间戳、完整解码、响度和编码后的修正画面。本稿是 Codex 对 Opus 原片的机械修正，不冒称由 Opus 新制作或验收。
