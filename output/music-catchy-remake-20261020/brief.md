## 方向比较 → 选择
| 方向 | 做法 | 取舍 |
|---|---|---|
| A 频谱 / 球体（v1） | 中心球 + 频谱等 drop | 已被退回：只在“等”，没回答“为什么” |
| B 鼓机 / 脑子角色 | 一个会打鼓的小脑袋 | 可爱，但很难把“重复”和“低音变薄”画成看得见、可比较的东西 |
| **C 踩拍之路 ✔** | 一拍一块石头，小家伙一拍一跳；石头厚度 = 实测低音；虚线框 = 它猜的下一块；鸟瞰时整首歌是一行行小节，相似的小节同色 | 每个解释都是**同一个世界里的一种状态变化**（间距、厚度、虚线框对实物、颜色），可以连续推进，并有空间层次：近景角色 → 正面量尺 → 低角度玻璃石 → 巨石对比 → 鸟瞰整首歌 → 最终领奖台 |

## 视觉语言
- **世界**：深靛夜空、远处一圈随本曲**逐帧真实频谱**起伏的光柱、雾中网格地面、浮尘。石头是圆角瓷质块；低音薄的拍子变成蓝色玻璃薄片；三次 drop 是从高处砸下来的巨石，带冲击环和镜头震。
- **角色**：圆身、大眼、腮红、珊瑚色耳机、头顶一根带金色小珠的天线。落地挤压，起跳拉伸；点头时眯眼；铺垫时下蹲蓄力、身后泛光。
- **颜色语义**：珊瑚 = 拍子 / 真的；青 = 猜的；金 = 熟悉 / 重复；③ 中各重复组各有一种颜色。
- **镜头**：主要切点都落在本曲实测起音上；每次切换有一次轻推。走过的整行石头会沉入深处，前景始终干净；到 ③ 整首歌重新浮起，排成一行行小节。

## 科学边界（详见 SOURCES.md）
- 不说“上瘾 / 中毒 / 开智 = 变聪明 / 多巴胺按钮 / 越意外越爽 / 中等复杂度最上头”。“上头”只指想跟着动、想再听。
- 小家伙的“猜”是比喻，不是观众的脑测量。Cheung 2019 测的是和弦，不是这首歌；画面角标写明“非本曲”。
- 实测项：拍长（≈0.53 秒）、低音能量（石头厚度）、小节频谱相似度（颜色）。这些都不是逐音转谱。

## 成功标准
- 第 0 帧即完整出现问题。旁白、字幕（逐词点亮）和画面动作同步。三次 drop 留给音乐。结尾回答并从容落地。
- 未经人耳试听、未在实体手机上看过：“好听 / 清楚 / 上头”都需要用户本人判断。
