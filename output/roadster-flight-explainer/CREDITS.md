# Credits and source boundaries / 分工与素材来源

**Primary creative and code author: Claude Code / Opus 5.5.** Blender geometry, procedural materials, source staging, motion and cameras, explanatory animation/timeline, renderer, Remotion typography/cover, and `scripts/score.mjs` music/sound synthesis were authored through the Claude Code production workflow. **Codex: production support and independent review.** Source verification and frame analysis; early source pose/framing corrections; Blender installation and Metal tests; targeted startup cleanup and renderer compatibility fixes; duplicate background removal; x-ray contrast refinement; CJK font assets/coverage; free narration asset preparation, canonical timing and machine checks; finalization tooling and encoded-output QA. These targeted changes do not change Opus's primary authorship. See code and each render manifest for actual settings and results.

## Fonts and sound

- **Roadster Film Sans:** a subset/derivative of Noto Sans SC, with bundled real weights 500/700/900. SIL Open Font License text and provenance are in `support/fonts/` and the public font folder. Codex prepared the assets and coverage checks.
- **Mandarin narration:** Microsoft `zh-CN-YunxiNeural`, rate −3%, generated through the existing free Edge Read Aloud route. Asset hashes, measured timings and ASR evidence are in `support/narration/`. Phrase timings are ASR-index estimates, not forced alignment.
- **Music and effects:** Opus-authored deterministic code synthesis in `scripts/score.mjs`. Valve/gas/cut cues come from the same exported animation event table. This is not stock music or an external music-generation API.
- No paid media service was commissioned. No audio/phone aesthetic acceptance is claimed from technical metrics alone.
