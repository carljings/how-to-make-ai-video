## 原作学到了什么（`reference-source/` + 代理片逐秒看过）

- 我不照搬：不复制它的图像、版式、字体（Archivo）、具体镜头（独角兽、shoggoth、SAFE ENOUGH 印章、[MASK] 揭字、Regenerate 回卷）。借的是原则：物件化、逐词卡点、明暗节奏、冷幽默、钩子升级。

## 决定
- **片长 = 整首歌**：录屏音轨 0–155.467 s，4664 帧 @30 fps（片时 = 录屏时间）。原 MV 整首都靠持续发明撑住；用户上一支也要求加长到整曲。
- **音轨 = 用户录屏的原音轨**（`reference-original-audio.m4a`，sha256 `bd8d1104…`）：用户听到并选定的就是它；比仓库干净版响约 7.7 dB（−7.8 vs −15.5 LUFS）——用户反馈过“声音不要变小”。处理同前几支：一次恒定增益把真峰值压到 −1.0 dBTP（约 −2.2 dB，不压缩、不限幅、不闪避），末尾只顺着歌曲自身的衰减做余弦淡出。干净版只用来对时（`tools/compare_audio.py`：25 个窗口恒定 +0.221905 s，r ≥ 0.95，无漂移，无循环重启）。
- **节拍/逐词时间**：原作 `data/audio.json`、`data/lyrics.json`（132.007 BPM，1 拍 0.4545 s，1 小节 1.818 s）减 0.221905 s → `src/timing.json`；`tools/check_onsets.py` 独立检测录屏低频起音：277 个 kick 全部在 ±60 ms 内有起音，中位 +16 ms（半帧以内）。
- **画面**：纯 Canvas 2D，每帧是 t 的纯函数；Chrome 无头逐帧截图→ffmpeg。
- **色彩**：墨 #0B0B0D / 骨白 #ECE6D9 / 信号橙 #FF5A1F（只给“分数/AI 在追的东西”，唯一发光色）/ 灰阶注释；积木案例的蓝块是全片唯一一次蓝。语义：**橙 = 分数（写下的规则）**，**骨白 = 你真正想要的**。
- **字体**：Noto Sans SC 400/700/900（字幕、大字）、Noto Serif SC 900（术语、定律引文）、IBM Plex Mono 400/600（分数、标签、代码）、Barlow Condensed 800（英文大字 I'M UPPING MY SCORE / OBEY）。全部 OFL，子集打包，服务器与 M4 出字一致。
- **安全区**（抖音界面）：主字幕 x 84–930、y 200–560；关键画面 y 560–1400；注释 y 1400–1475；y>1500 与右侧 x>940（y 900–1700）只放背景。
- **读速**：主字幕 ≤ 20 字、两行以内、每条 ≥ 2.2 s；注释是“可选阅读”（来源与边界），可以小。
- **开头**：第 0 帧就是最强画面 + 悖论：“得分最高的这条船，从没跑完比赛”。
- **结尾**：分数刷到 ∞ → NaN（指标失去意义）→“下次看到高分，先问一句：这分是怎么来的？”→“↻ 重新训练”被点下，回到第 0 帧（可无缝循环）。
