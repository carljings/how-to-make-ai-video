# r5 分镜：留住前几秒、提高完播（三个剪辑版本）

2026-10-25 用户批准：开头采用“2.51 → 20”（与主标题“三阶魔方再乱，也能20步内还原？”一致），并要求三个方案都做（“123 do all”）。三个版本共用一套代码，用页面参数选择：`src/index.html?v=full`、`?v=mid`、`?v=light`。

**不变**：Opus 原片的画面语言和制作链：Canvas 2D 自写魔方、Chrome 逐帧导出、原有字体（新增字形取自同一 Noto Sans SC 2.004 母版，SHA-256 a3041811…）、配色、镜头运动、Web Audio 原音色、120 BPM、无旁白。不加新的 UI 元素（r2 被否的教训）。所有数字和措辞沿用已核实的审定稿口径；新增句子只重组已有事实。

## 制作与检查

1. 每个版本逐秒拼图审查（字幕、遮挡、衔接），修正后再全片渲染。
2. 三个版本并行渲染（本机 CPU，SwiftShader；与 r4 的 Metal 渲染逐帧对比 SSIM 0.985）。
3. 检查：逐秒拼图、关键动作连续帧、字幕逐句对照、数字复核、−14 LUFS / 真峰 ≤ −1.5 dBTP、完整解码。我听不到声音，配乐只能做电平和卡点检查。
