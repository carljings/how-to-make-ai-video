# Roadster v3「比墙还陡」——比墙还陡，它怎么掉不下来？

[English](README-v3.md) · [分工与来源](CREDITS-v3.md) · [制作进度（英文）](PRODUCTION_STATUS.en.md)

抖音竖屏科普短片，58.3 秒，1080×1920，30fps。一部片，讲两场彼此独立的官方演示。

1. **坡道（特斯拉，2026.10.16）**：车开上一座倒 C 形混凝土坡，越过垂直。片子讲它为什么掉不下来：
   - 风扇抽走车底缝隙里的空气，外面的空气就把车压在坡上（说是吸，其实是压）。
   - 这股压力始终指向坡面，倒悬段上甚至朝上；重力始终朝下。压紧了，轮胎才抓得住。
   - 到了坡顶，车底下没了坡，压力逐步变弱，最后消失。
2. **腾空以后**：换车上自带的高压气接力。气往下喷，车就被往上推。
3. **另一场演示（马斯克，2026.10.16）**：推力偏离重心，整车翻转。这一段与坡道之间用纯黑隔开，并在角标和配音里写明是另一场演示。
4. **结尾**：贴着坡，借的是空气的力；腾了空，花的是自己的气。自己的气，总有喷完的时候。

导演方案见 [CREATIVE_DIRECTION-v3.en.md](CREATIVE_DIRECTION-v3.en.md)，分镜见 [storyboard-v3.zh-CN.md](storyboard-v3.zh-CN.md)。v1、v2 原样保留。

## 重建与示意的边界

- **按原片画面重建**：
  - 坡形和场地；
  - 爬坡、过坡顶、空中转为水平；
  - 向下的气柱、白雾、落入雾中。原片里着地被白雾挡住，片中不画。
- **拟合，不是测量**：车的尺寸、坡道曲线、姿态和机位都是拟合结果。新机位和变速都写在角标里。
- **原理示意（角标「原理示意」「剖面」）**：
  - 剖面切开的坡道、车底缝隙、风扇吸气环；
  - 空气短线、冲击短线；
  - 所有箭头、压力罐和喷口位置。

  箭头方向按几何计算：压力沿当地坡面法线，重力始终朝下，反推力与所画气柱正相反，力矩按 r×F。箭头长短只是示意。
- **不出任何数字**（压力、力、质量、推力、续航）；不说悬停，不说无吊索，不说能实用飞行。翻转片里的线缆保留在画面中，不讨论。
