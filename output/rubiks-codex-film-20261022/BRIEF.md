# 魔方科普 · Codex 接手制作

本轮用户明确授权由 Codex 继续制作视频、检验此前学习成果。因此本片由 Codex 负责分镜、动画、声音、渲染与检查；不调用受限 Opus，不更改其他影片、网站、试作或账户配置。

接续的是用户最后确定的魔方 2–3 分钟主题，依据现有脚本 v2：起源、合法组合数、20 步证明、人类竞速、LBL/CFOP/Roux、耿暄一与王艺衡近期成绩。保留事实口径和覆盖范围，镜头适配全原创代码绘制，不采用脚本里尚不存在的手部实拍。

## 成功标准

- 交付可播放的完整 9:16 MP4，含清楚中文旁白、同步字幕、原创配乐与动作音效。
- Canvas 每帧由时间确定。魔方逐层转动与分阶段解法采用现有已验算数据，另用 cubing.js 核对几何与目标；不把一个还原动画换三种标签。
- 先让观众看到问题，再让角棱分离、朝向与约束、状态压缩、上限与下限、三种方法的目标在画面中成立。保持一个主焦点。
- 成绩数据明确给出核验截点。保留单次与平均、纪录与夺冠、步数与秒数的区别，不假装是实际纪录复盘。
- 结尾回到开场同一只魔方，完成最后动作与音乐落点，再给出足够停留；不突然切断，不用长静音伪装余韵。
- 验证编码成片的连续运动、字体、遮挡、读速、音画时长、响度和最后数秒。听感与实体手机未检验的部分如实说明。

## 制作范围与成本

本机程序绘制与合成，无付费图片/视频生成、无外部发布。沿用已有 Edge TTS 工具产生中文配音；不启用收费云语音 API。若服务不可用，先保留完整制作素材，不冒充已有配音。

镜头与字幕在完整声音时间轴上统一排布。源代码和输出独立保存在本目录，旧片不覆盖。
