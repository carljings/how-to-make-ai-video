## 音乐：从录屏里取出干净的一遍

| 量了什么 | 结果 |
|---|---|
| 循环点 | 录屏开头放的是上一遍的尾巴，0.604–0.698 秒有 95 毫秒静音，之后抖音视频从头放；把 0.70 秒起的 0.6 秒和后面做互相关，19.64 秒后重复（r = 0.995）。干净的一遍：录屏 0.698–20.112 秒 |
| 节拍 | 起音包络的自相关在 75 BPM 最强；动态规划跟拍得到 49 个脉冲，直线拟合周期 0.40012 秒，残差大多在 ±10 毫秒内；第一拍在片内 0.0533 秒 |
| 句子 | 抖音字幕在 0.0、3.2、6.4、8.4、10.0、13.1、16.4 秒换句，正好每句一小节（3.2 秒） |
| 每个字 | Demucs（htdemucs）分出人声，torchaudio MMS_FA 按拼音强制对齐，47 个字都对得上 0.2 秒网格：对齐时刻比网格早 0–70 毫秒（对齐模型一格 20 毫秒，偏向辅音起点），另用人声的起音检测逐个核对，多数起音在网格 ±30 毫秒内；只有“年”在两格之间（17.51 秒，取对齐值）。网格时刻写进 `src/timeline.ts` |
| 长度 | 6 小节 = 19.206 秒；成片取 19.2 秒（576 帧），在第7小节强拍前 0.06 秒切断，与开头第一拍前 0.053 秒对称，循环不错拍 |
| 响度 | 原片 −9.8 LUFS、真峰值 +0.2 dBTP（44.1 kHz）；soxr 重采样到 48 kHz 后真峰值 +0.4 dBTP。降 2.1 dB：−11.9 LUFS、−1.7 dBTP；试编 AAC 256k 只多出约 0.1 dB，成片 −1.7 dBTP。比“约 −11.5”低 0.4 LU，是因为 48 kHz 下量到的峰值更高 |

## 实现

| 部分 | 做法 |
|---|---|
| 框架 | Remotion 4.0.534 + React 19，与光遗传学 V3 同版本；每幕一个 `<Sequence>`，在 Remotion Studio 时间线上按名字显示 |
| 时间 | `src/timeline.ts` 是唯一时间来源：节拍网格、47 个字、六幕、五个转场、震屏、每幕里的动作（敲、跳、睁眼、盖章、刹车、吹走、心跳）都从字的时刻推出来 |
| 画面 | 全部是 SVG 和 HTML：像素画由文字位图生成（`src/art/pixel.tsx`），吉祥物按 Claude Code 标志的比例（12×8 身体、四条腿在第1、3、8、10列）；世界地图是 Natural Earth 陆地栅格成 805 个点，同一组点可以平铺成地图，也可以投影成球，第3幕结尾在两者之间插值 |
| 歌词 | `src/ui/Lyrics.tsx`：每个字一种动法和一种样子（羽毛、重砸、弹出、下沉、慢拉伸、眼皮张开、张望、抖、印章、聚光、吹入、旋转、东倒西歪、花瓣、心跳），砸进来的字带两层残影代替运动模糊（不用 CSS blur） |
| 循环 | 最后一拍起，一扇心形的窗从「心」长大，窗里渲染的是时间 −0.34→0 秒的画面，所以最后一帧接得上第一帧 |
| 声音 | 只有这段歌；`scripts/music.mjs` 精确到样本地截取、重采样、降增益，头 5 毫秒、尾 15 毫秒淡入淡出防爆音 |
| 字体 | Noto Serif SC 900（歌词）、Noto Sans SC 700、JetBrains Mono 500/800，只含用到的 158 个字符 |

`npm run verify` 17 项全部通过，记录在 [out/verification.json](out/verification.json)：片长正好6小节、每个切点在强拍上、47 个字都在网格上且顺序正确、歌词与原曲一致、字体覆盖所有用字、12 帧按不同顺序渲染两次结果一致、最后一帧与第一帧 PSNR 30 dB、音乐切片 19.2 秒 48 kHz、1080×1920 30fps 576 帧、H.264 High yuv420p BT.709、AAC 48 kHz 立体声、音画同时开始且 19.2 秒、全片解码无错误、−11.9 LUFS、真峰值 −1.7 dBTP、成片音轨与音乐切片相关系数 0.9999 且偏移 0.00 毫秒（画面按这段音乐定时，所以这一项就是音画同步检查）。渲染 576 帧约 70 秒，成片 15.4 MB。README 里的命令都运行过：在一份不含 node_modules 的副本里 `npm ci` → `npm run music`（生成的 music.wav 与正式用的逐字节相同）→ `npm run build`（渲染、封面、17 项检查全部通过，12 帧的哈希与正式版完全一致）；`npm run studio` 能启动并响应；无声渲染命令得到 576 帧、没有音轨的视频；`node scripts/map.mjs --step=4.5` 重新生成的 land.ts 与原来相同。

## 审片中发现并改掉的问题

| 问题 | 处理 |
|---|---|
| 黎明特写太紧：帽子和手臂出画 | 吉祥物从 50 缩到 40 像素一格，帽子改成往右下垂，绒球留在画内 |
| 月亮背后一圈灰色圆盘 | 改成柔和的光晕 |
| 纸上的红点太多像脏点 | 26 个减到 14 个，颜色更淡 |
| “忙碌”左边的速度线在静帧里像一道删除线 | 改成漫画式的抖动短线，闪烁到“是否”时停 |
| 第4幕字章在左下角压住状态栏；行星阴影太重像灰色月亮 | 轨道半径 250→232，字章从小 AI 身后经过；阴影减半 |
| 第3→4幕米色淡到深蓝时有三帧灰 | 夜空改成从地球边缘向外展开 |
| 跳上地球时小 AI 跳出卡片顶边 | 跳跃弧度 160→56 像素 |
| 「心」夹在文字和卡片之间，压到“年” | 挪到“的”后面，同一行 |
| 心形窗在纸上看不见（窗里窗外都是纸） | 给窗加一圈红色像素心形边，边宽最多 26 像素 |
| 春风的白色风线在静帧里像横杠 | 改成两道弯曲的风痕 |
| “轻”淡入太慢，第一拍不明显 | 淡入从 0.3 秒改成 0.16 秒 |
| 帽子绒球在封面上像一块白方块 | 绒球右下加一格浅灰阴影 |

## 还要用户做的

1. 手机上带声音完整看两遍（看第一遍，再看循环接缝）：字和唱是否对得上，第一秒是否抓人，残影和震屏是否晃眼。
2. 私密发布后在抖音界面里确认：歌词和明信片没有被右侧按钮列和底部文案挡住（按右侧约170像素、底部约480像素留空设计）。
