# Roadster v5《空气现形》

Opus 5.5自由主导创意、分镜、代码动效与原创程序配乐；Codex提供素材核查、真实配音、字体、本机渲染与质检。模型实际为claude-opus-5-5，effort为max。

完整成片：[roadster-v5-air-revealed.mp4（原文件未收录，见归档状态）](../archive-20261025/README.zh-CN.md)。56.4秒，1080×1920，30fps，1692帧。最终编码−14.1LUFS/−1.8dBTP。

## 这版的观看顺序

1. 倒悬车辆和落尘提出“它凭什么不掉”；
2. 冲击波切换空气视角：风扇抽气、外界压力、轮胎抓地；
3. 顶板尽头缝口敞开，压力束消失；
4. 冰蓝高压气流呈现反作用，另一场演示解释偏心喷气与翻转；
5. 用“借空气”和“花自己的气”收束，点出储气有限。

顶部平直段和推断拟合姿态沿用原片依据；受力、喷口、储气与粒子都是原理示意，非官方CAD或实测数据。翻转原片可见细线保留，作用未公开。来源发布于2026-10-16，不称“今天”。
