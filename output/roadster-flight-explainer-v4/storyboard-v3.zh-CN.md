# 「比墙还陡」 v3 分镜（约 58 秒，9:16，1080×1920，30fps）

导演：Opus 5.5。坡道与翻转合成一部片。配音逐字见 `narration-lines-v3.json`（16 段，155 字）。下表时间是剪辑意图，配音实测后以实测为准重排：顺序和卡字点不变，画面停留时长吸收误差。v1、v2 原样保留。

**核心问题：** 比墙还陡，它怎么掉不下来？
**因果链：** 风扇抽走车底缝隙里的空气 → 外面的空气把车压向坡面（说是吸，其实是压）→ 压紧了轮胎才抓得住，一路开上去 → 这股力始终指向坡面，坡怎么弯它怎么转，重力始终朝下 → 坡到头：车底越出坡沿，这股压随缝隙敞开逐步变弱，车底完全离开坡面时消失 → 腾空以后，换自带的高压气接力：气往下喷，车被往上推 → 另一场演示：推力偏离重心，整车翻转 → **贴着坡，借的是空气的力；腾了空，花的是自己的气。自己的气，总有喷完的时候。**
**结构暗线：** 第 18.6 秒开始搭一张「多次曝光」底片，只搭到坡顶，坡顶之外故意留黑。结尾回到这张底片，把腾空的那一半补完。观众到最后才看到完整的一张图。

## 字体与文字

- 字体是 Noto Sans SC（OFL）的子集。巨字用 900，结尾卡和动态字用 700/900，字幕用 600，标注用 500，角标用 300。Codex 按 v3 最终文字重做子集。
- 同一时刻屏幕上最多：一个角标、一条字幕（或一个动态字／结尾卡）、一个标注。
- 字幕无底框，柔和投影，居中，基线 y≈1330，最宽约 860px，避开右侧按钮区。
- 颜色有含义：暖金是借来的空气，冰蓝是自带的气，红是作用在车上的推力，白是重力和中性陈述。字幕按词着色，和画面一致。

## 事实边界（落在画面里，不做说明卡）

- **原片动作（重建）**：坡形、爬坡、过坡顶、空中转为水平、向下气柱、白雾、落入雾中，全部按特斯拉 2026.10.16 发布的视频重建。新机位和变速都写在角标里。空中姿态从原片帧拟合，不编造。
- **示意（角标「原理示意」）**：缝隙、风扇吸气环的位置、空气短线、冲击短线、所有箭头、压力罐、喷口位置。箭头方向由几何算出：压向坡面的箭头沿当地坡面法线，重力始终朝下，反推力与所画气柱正相反，力矩按 r×F。箭头长度只是示意，不标任何数值。
- **坡顶交接是示意**：风扇吸附有一定的漏气余量，不是一漏就失效。压向坡面的箭头随缝隙敞开逐步变短，车底完全离开坡面时才消失。不声称原片测到了某个突然失效的时刻。腾空以后惯性和重力照常起作用，高压气喷射是接手的新的主动手段，不是唯一的影响因素。
- **不说的**：压力、推力、气量、罐容量和数量、喷口数量、高度、速度、续航，一律不出数字。不说白雾成分，不说悬停，不说无吊索，不说能实用飞行。翻转片里的线缆保留在画面中，不讨论。
- **两场演示分开**：中间是纯黑分隔，角标写明「另一场演示」，配音也说「另一场演示里」。不暗示翻转是冲出坡道后发生的。结尾那张多次曝光底片只用坡道这一场的数据：坡上靠压，离坡靠喷，同一场演示里本来就两种都有。
