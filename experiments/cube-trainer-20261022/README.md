Codex 本次新增了公式库界面、训练引擎与题库、作答反馈、独立验算，以及它们和现有单个 3D 播放器的接入。另修复了连续重启播放导致旧播放循环推进新路线的问题。

## 可以操作的内容

- 公式库：F2L 41、OLL 57、PLL 21、CMLL 42，另有 LBL 10 与 LSE 3 个演示，共 174 个；支持搜索、分组、逐步播放和完成状态。含整体转动的原公式与固定视角等价演示分开标注。
- 十字规划：36 题，分 1 步、2–4 步、5–8 步；先输入整段方案再判定，不限于参考答案。反馈四条白棱的位置与朝向，可分别播放自己的方案或参考路线。
- 第一组预判：24 题；判断给定十字路线结束后的角块、棱块位置及两张指定贴纸朝向。
- 扩展十字：18 题，X / XX / XXXCross 各 6 题；预测完成哪些槽，可改写路线并核对实际结果。
- 可选 15 秒练习观察；本次页面内记录尝试次数与正确次数。

## 重现

在本目录执行：

```sh
npm ci --ignore-scripts --no-audit --no-fund
node tools/gen-library.mjs
node tools/gen-training.mjs
node tools/verify-learning.mjs
npm run build
npm run dev -- --host 127.0.0.1 --port 4293 --strictPort
```

所需参考数据已随源码保存在 `tools/reference-cases.json`，生成时不依赖原项目的临时输出目录。

## 范围

当前为固定题库，常规打乱来自随机 22 步筛选，并非均匀随机状态。十字参考解按固定白底、面转动 HTM 精确最短；扩展路线仅保证目标成立，没有宣称全局最短。输入方案限 U/D/L/R/F/B 及其逆转和半转。每个标准情况只收录有限写法，并非所有公式变体。
