# 2 · 路线 A：用视频模型生成镜头

[English](../02-path-a-generate.md) · **简体中文**

你描述一个镜头，视频模型把它画出来。凡是有**人物、场景、天气、动物、真人或动漫风格**的内容都适合走这条路线：短剧、广告、MV、空镜。

## 模型能接受哪些输入

| 模式 | 你提供 | 适合 |
|---|---|---|
| 文生视频 | 一段提示词 | 建立镜头、空镜，以及没有固定角色的画面 |
| 图生视频 | 首帧（加提示词） | 精确控制构图；接上一个片段的最后一帧 |
| 首尾帧 | 两张图 | 两个状态之间可控的运动或变化 |
| 参考生视频 | 角色 / 场景图片，在提示词里引用 | **固定角色**：任何故事的骨架 |
| 原生音频 | 同上，打开音频 | 台词、环境声、音效与画面一起生成 |

一次生成通常是 **5–15 秒**。长一点的片子就是很多片段在剪辑时拼起来的，所以分镜才这么重要。

## 选模型

常用的模型家族有 Seedance（字节跳动）、可灵 Kling（快手）、海螺 Hailuo（MiniMax）、Vidu（生数科技）、Veo（Google）、Runway 和 Luma，以及可以在自己 GPU 上运行的开放权重模型，如 Wan（通义万相）和 HunyuanVideo（混元）。（OpenAI 的 Sora 已于 2026 年停止服务：App 于 4 月 26 日关闭，API 于 9 月 24 日关闭。）版本几个月就换一轮，所以按自己的需求比较，不要只看排行榜。在国内平台上使用这些模型（即梦、小云雀、LibTV、LiblibAI、TapNow、Flova）见[第 6 章](06-platforms-compared.md)；类似 Toonflow 的开源与闭源工作台见[第 7 章](07-tools-like-toonflow.md)。

| 要看什么 | 为什么重要 |
|---|---|
| 最长片段时长、分辨率、画幅 | 抖音 / TikTok / Shorts 用 9:16，YouTube / B 站用 16:9 |
| 参考图：能放几张，提示词里怎么引用 | 决定整个故事里角色是否一致 |
| 原生音频和口型同步 | 如果支持你需要的语言，可以省掉单独配音和对口型 |
| 每秒 / 每次生成的价格 | 一集 3 分钟就是 15–20 个片段，这还没算重做 |
| 商用条款 | 有些套餐不允许商用 |
| 开放权重 | 本地运行，没有按片段计费，但需要很强的 GPU |

## 实际可行的流程

[`examples/`](../../examples/README.zh-CN.md) 里那集 16 个片段、3 分 16 秒的竖屏短剧就是这样做的（在 Toonflow 画布里用 MiniMax 模型，9:16，768p，原生音频）。

1. **剧本 → 分段。** 把剧本切成不超过模型上限的段（每段 10–15 秒）。每一段是一个连续的时刻：一个地点、一个动作、一两句台词。
2. **先做参考图。** 每个主要角色一张（正面和侧面、全身、本集穿的那套衣服），每个场景一张。挑最好的那张**锁定**；一集做到一半，永远不要重新生成参考图。
3. **每段一条提示词**，用[镜头提示词模板](../../templates/zh-CN/shot-prompt.md)。参考图按固定顺序挂载，在提示词里按编号引用（例如 `{{ref 1}}` = 女主，`{{ref 2}}` = 街道）。
4. **每段先生成一次，然后检查。** 每段生成一次，用 [`tools/review.sh`](../../tools/review.sh) 给每个片段做一张抽帧拼图，只重新生成失败的。
5. **全部记进[制作日志](../../templates/zh-CN/production-log.md)：** 段落、提示词、参考图及其顺序、输出文件、状态。生成有时显示超时但其实已经成功；重跑之前先查日志和输出文件夹，免得付两次钱。
6. **用 [`tools/stitch.sh`](../../tools/stitch.sh) 拼接：** 按分镜顺序硬切，再加片头、字幕和可选的背景音乐。见[第 5 章](05-edit-and-export.md)。

## 提示词的结构

国内模型都能直接读中文提示词：

```
[景别]   中近景，平视，35mm，浅景深。
[主体]   {{ref 1}}：年轻女子，褪色的灰色道袍，头发用木簪挽起，肩上挎着布包。
[动作]   她在路边停下，抬头看红绿灯，然后迟疑地后退一步。
[运镜]   缓慢推近。
[场景]   {{ref 2}}：夜晚繁忙的城市路口，湿漉漉的柏油路，霓虹倒影。
[光线]   左侧冷色路灯，身后店铺的暖光。
[情绪]   格格不入、好奇、有点害怕。
[声音]   城市车流，远处一声喇叭。她小声说："这么多人……"
[避免]   画面文字、前景多余的人、换装。
```

每条提示词里对角色外貌的描述要*一字不差*。每个片段**只放一个动作**；两个动作（"她转身跑向汽车并打开车门"）正是模型开始跑偏的地方。

## 片段之间保持连贯

- **上一段的尾帧 → 下一段的首帧。** 连续动作时，用第 N 段的最后一帧作为第 N+1 段的首帧：
  `ffmpeg -sseof -0.1 -i clip07.mp4 -frames:v 1 -update 1 clip07_last.png`
- **在动作上或视线上切。** 硬切比慢慢叠化更能掩盖细小的差异。
- **特写给情绪，全景给环境。** 多人的全景最容易出现脸部漂移。
- **一集一套服装。** 换装是让角色"认不出来"最快的方式。

## 常见问题与解决

| 问题 | 解决 |
|---|---|
| 画面里的文字是乱码（招牌、标题） | 要求不出现文字，剪辑时再加 |
| 脸或服装漂移 | 更强的参考图、更近的景别、更少的人、更短的动作 |
| 手部、物体粘连 | 藏住手、简化道具、早点切走 |
| 物理感发飘、像慢动作 | 写明"正常速度"；裁短片段；在动作上切 |
| 口型对不上 | 台词改短；或者不带台词生成，之后再配音（第 4 章） |
| 表情没有变化（MiniMax H3） | 一个镜头只放一个表情节拍：拆成 2–3 秒的短镜头（[第 8 章](08-skills-plugins-tools.md#这些项目教会了什么)） |
| 片段结尾很乱 | 在 `shots.txt` 里裁掉尾巴（`clip.mp4 0 9.2`） |

## 版权与标识

- 用于商业发布前，确认你的套餐是否允许**商用**。
- 未经本人同意，不要生成**真实人物**（或其声音）。
- 很多平台要求**标识 AI 生成内容**，中国自 2025 年 9 月起已强制要求对 AI 生成内容进行标识。上传时打开平台的 AI 标识。
