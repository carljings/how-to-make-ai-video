# 红果短剧和爆款 AI 视频，究竟用什么工具制作？

[English](../hit-video-workflows.md) · **简体中文**

核查日期：**2026 年 10 月 16 日**。重读工程[第6章](06-platforms-compared.md)、[第7章](07-tools-like-toonflow.md)，再核对主创访谈、产品官网、LibTV Skills 仓库和本工程诺奖 V3 源码。本轮为资料核查，**没有付费生成、安装、订阅或进行同剧本画质测试，也未重新观看这些第三方成片、审计其后台数据**。

**制作工作台与视频模型 API 可以组合使用。** 人可以手动操作工作台，也可以让 Agent 调用工作台公开接口，或直接调用模型 API。下面的公开案例不足以统计哪条路线占行业多数。

## 先分清五个环节

| 环节 | 例子 | 解决什么问题 |
|---|---|---|
| 观看与分发 | 红果、抖音 | 把成片交给观众；上架平台不能反推出制作工具 |
| 编剧与策划 | 人类编导＋大语言模型助手 | 选题、剧本、分镜、提示词和审片决策 |
| 制作工作台 | LibTV、TapNow、小云雀；开源替代见第7章 | 组织角色、参考、镜头与生成任务；自动化能力各不相同 |
| 生成模型与调用入口 | Seedance、可灵等；网页、官方 CLI 或 API | 生成画面、运动，有的同时生成声音；接口是调用方式 |
| 后期与交付 | Remotion、剪映、Blender、ffmpeg 等 | 剪辑节奏、合成、准确文字、声音、字幕与导出 |

红果既有真人拍摄作品，也有 AI 内容，不能把所有红果爆款归为 AI 生成。[3月7日关于抖音回应的报道](https://www.ithome.com/0/926/825.htm)也明确区分了两类制作。

## LibTV 到底处在哪一层？

官方 [libtv-labs/libtv-skills](https://github.com/libtv-labs/libtv-skills) 提供创建会话／发送指令、上传素材、查询进度和下载结果，并返回项目画布链接。因此它既能供人操作，也支持 **Agent → LibTV OpenAPI → 生成结果**。

MIT 开源的是 **Skills 代码**，不代表 LibTV 在线服务或底层模型开源。公开的会话接口也不等于完整剪辑时间线 API；逐镜精确模型参数、每次局部修改的持久化和完整可编辑导出，仍需实测。本轮没有安装、登录生成或验证导出后再编辑的完整流程。

现有证据支持把 LibTV 作为**可视化镜头管理和多模型制作**候选，不能据此称它画质最好或承包了多数红果爆款。本次样本中，小云雀有更明确的具名长剧生产案例；这只是证据差异，不是画质胜负。

源码明确使用 `doubao-seedance-2-5-260628` 和方舟 `contents/generations/tasks` 接口。这证明工程实现及记录的制作流程，**不证明它已经成为爆款，也不代表本轮重新核验了在线服务可用性**。原始模型片段和分轨并未全部入库，本轮未重看成片。

历史日志的**约245元是估算，不是账单**，包含当时的样片、高清生成与返工。[用户后来更新的预算规则](../../CLAUDE.md)要求：分镜确认后直接 **720p**，不做480p样片或1080p生成，复用参考图，每次花费先列预算批准。历史制作命令不能覆盖新规则。

## 对你三类视频的建议

以下属于根据现有项目和案例提出的**选型建议，未经同题实测排名**。

| 优先级 | 建议路线 | 要验证的实际收益 |
|---|---|---|
| **第一：高质量科普** | 保留 Opus 辅助研究策划，Remotion／Canvas 控制精确解释；确实有助于讲明白的镜头再用视频模型。需要可追溯记录和自动化时，继续沿用现有 API 路线 | 科学事实、因果、单位文字、声音同步、不断推进的动效；整片带声音在手机上验收 |
| **第二：发明家猫** | 固定角色参考，先做一个短动作；比较 LibTV 画布与现有生成路线，再决定是否订阅 | 猫脸、毛色、护目镜、爪子接触道具和情绪节奏是否稳定 |
| **第三：AI短剧** | 剧本到分集可比较小云雀 Agent；逐镜导演控制可比较 LibTV／TapNow；确有自托管或集成需求再考虑 Toonflow／ArcReel | 角色和声音连续性、表演对白、单镜返工、可编辑导出 |

**API 不会天然提高画质。** 要对齐具体模型版本、参数、参考、提示词改写和输出压缩。工作台可能帮助整理资产、组织提示词；直连 API 可能更利于复现和自动化。两者都不能保证爆款。

从这些案例得到的内容判断是：值得测试清楚的设定、具体的情绪、有目的的动作和剪辑。它不是“用了某工具、剪得快、套前三秒公式就会爆”的因果证据。账号继续执行[准确标题、相关标签、开场和数据测试标准](08-douyin-science-growth.md)。

## 成本怎样比才有意义？

**10月16日**读取的 [LibTV 官网横幅](https://www.liblib.tv/)显示：**Seedance 2.5 720p 有参低至0.19元／秒、无参低至0.46元／秒**，带至尊会员、限时条件。它已经不同于第6章较早的 Seedance 2.0 年费快照。完整套餐付款额、“有参”具体定义、输入计费与实际积分兑付未核验；这些只是**宣传最低价，不是批准的制作预算**。

公平比较应固定同一15秒、720p分镜，以及模型版本、参考、音频条件和导出权益。记录必须支付的套餐金额、实际消耗积分、参考图、废片、重做和后期。现金付款与积分消耗分开记，既不要每条片都摊入整年会员费，也不要重复计算积分成本。

**每秒有效成片成本＝归属于本片的制作成本÷最终采用秒数。** 未使用／可能到期的积分、最低前期付款也要单列。本轮没有执行付费对照；任何实际花费都先走逐项预算批准，暂不能宣布哪家最便宜或画质最好。
