# 镜头提示词模板（路线 A）

分镜表的每一行复制一份。参考图按列出的顺序挂载；同一组参考图出现在哪里，顺序都保持一致。

```
镜头 <#> · <时长> 秒 · <画幅>
参考：{{ref 1}} = <角色>，{{ref 2}} = <场景>

[景别]   <景别>，<角度>，<焦段>，<景深>
[主体]   {{ref 1}}：<每次都用完全相同的外貌描述：年龄、发型、服装、道具>
[动作]   <只写一个动作，用现在时，并写清结束状态>
[运镜]   <固定 | 缓慢推近 | 左摇 | 手持跟拍 | ……>
[场景]   {{ref 2}}：<时间、天气、关键细节>
[光线]   <方向、颜色、光的氛围>
[情绪]   <两三个词>
[声音]   <环境声、音效>。<角色名>说："<一句短台词>"
[避免]   画面文字、前景多余的人、换装、慢动作
```

## 完整示例

```
镜头 4 · 12 秒 · 9:16
参考：{{ref 1}} = 陈小满，{{ref 2}} = 夜晚的城市路口

[景别]   中近景，平视，35mm，浅景深
[主体]   {{ref 1}}：19 岁女生，黑发用木簪挽起，褪色的灰色道袍，左肩挎着布包
[动作]   她在路边停下，抬头看正在变灯的红绿灯，迟疑地后退一步
[运镜]   缓慢推近
[场景]   {{ref 2}}：夜晚繁忙的十字路口，湿漉漉的柏油路，霓虹倒影，身后车流驶过
[光线]   左侧冷色路灯，身后店铺的暖光
[情绪]   格格不入、好奇、有点害怕
[声音]   车流声，远处一声喇叭。小满小声说："这么多人……"
[避免]   画面文字、前景多余的人、换装、慢动作
```
